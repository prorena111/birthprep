출산펭귄 (이하 "앱")

시행일: 2026년 9월 19일

요약

이 앱은 개인정보를 서버로 보내지 않습니다. 회원가입이 없고, 계정도 없고, 수집한 정보를 저장하는 서버 자체가 없습니다. 입력하신 모든 내용은 사용하시는 기기 안에만 남고, 앱을 삭제하면 함께 사라집니다.

  • 위치 정보 (GPS) — 지역은 사용자가 목록에서 직접 고릅니다

  • 광고 식별자 (ADID/IDFA)

앱은 사용자를 식별하거나 여러 기기에 걸쳐 추적하지 않습니다.

2. 저장 방식과 보관 기간

모든 정보는 기기의 앱 전용 저장 공간(Android SharedPreferences / iOS UserDefaults)에 저장됩니다. 다른 앱은 이 영역에 접근할 수 없습니다.

보관 기간은 사용자가 앱을 삭제할 때까지입니다. 앱을 삭제하면 저장된 내용이 운영체제에 의해 함께 삭제되며, 별도의 백업본은 남지 않습니다. 앱 안에서 개별 항목을 지우거나 바꾸는 것도 언제든 가능합니다.

참고: 기기·계정 설정에서 앱 데이터 백업(예: Android 자동 백업, iCloud 백업)을 켜두신 경우, 운영체제가 앱 데이터를 사용자 본인의 클라우드 계정에 백업할 수 있습니다. 이는 사용자와 운영체제 사업자 사이의 기능이며 앱 제공자는 해당 백업에 접근할 수 없습니다.

3. 제3자 제공 및 위탁

개인정보를 제3자에게 제공하거나 처리를 위탁하지 않습니다.

다만 다음의 경우 외부 서비스와 통신이 발생합니다. 이때 전송되는 것은 검색어와 같은 조회용 정보뿐이며, 위 1항의 개인정보는 포함되지 않습니다.

5. 이용자의 권리

서버에 보관되는 정보가 없으므로, 열람·정정·삭제는 모두 앱 안에서 즉시 가능합니다.

  • 열람·정정: 설정 화면에서 저장된 값을 직접 확인하고 바꿀 수 있습니다.
  • 삭제: 개별 항목을 지우거나, 앱을 삭제하면 전부 사라집니다.
  • 처리 정지: 알림을 끄면 관련 처리가 즉시 중단됩니다.

6. 만 14세 미만 아동

이 앱은 임신·출산을 준비하는 성인을 대상으로 합니다. 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 알면서 수집하지 않습니다.

앱에 입력하는 아기의 생일 등은 보호자가 스스로 관리하는 정보이며 기기 밖으로 전송되지 않습니다.

7. 안전성 확보 조치

  • 개인정보를 외부로 전송하지 않는 구조로 설계 (서버 미보유)
  • 기기 내 앱 전용 저장 영역 사용 — 다른 앱의 접근 차단
  • 오류 메시지에 저장값이나 API 키가 노출되지 않도록 처리

8. 안내의 정확성에 관하여

이 앱은 정부·공공기관이 아니며, 어떤 기관과도 제휴하거나 위탁받지 않은 개인 개발 앱입니다.

앱이 제공하는 정부 지원금·검진·예방접종 안내는 공개된 공식 자료를 정리한 것이며, 법적·의학적 자문이 아닙니다. 항목마다 정부24·복지로·질병관리청· 국민건강보험공단 원문 링크를 함께 둡니다.

  • 지원금 금액은 확인 시점을 함께 표시하며, 확인한 지 6개월이 지나면 앱이 스스로 금액 표시를 중단합니다.
  • 검사·예방접종 일정은 일반적으로 통용되는 기준이며, 실제 일정은 의료진이 정합니다.
  • 신청 전에는 반드시 공식 창구에서 확인하시기 바랍니다.
